## 1. 前言

随着原神 2.6 版本的更新，目前国服的审核环境越来越差。

## 2. 关于转国际服的利弊

第一是没有防沉迷系统，想不限制时间的孩子很友好。二来是没有莫名其妙的各种和谐，但值得注意的是国际服也是有视角和谐的，所以某些 LSP 就别想了。还有要注意的是国服与国际服的数据不互通，所以做好重新开始的准备。

以下为教程部分。

## 3. 下载并安装原神国际服

### 3.1 Windows 平台部分

PC 端其实较为简单，国内可以直接访问并下载。这边建议可以先改一下 DNS 加快访问速度。之所以那么做是因为国际服官网的服务器是架设在国外的，所以自然就慢。

#### 3.1.1 修改 DNS（可选；若想直接安装可跳过）

1. 右击 Wi‑Fi 图标。

![步骤截图](./images/img-02.png)

2. 点击打开「网络和 Internet」设置。

![步骤截图](./images/img-03.jpg)

3. 单击「更改适配器选项」。

![步骤截图](./images/img-04.jpg)

4. 双击第一个选项。

![步骤截图](./images/img-05.jpg)

5. 点击「属性」。

![步骤截图](./images/img-06.jpg)

6. 双击「Internet 协议版本 4 (TCP/IPv4)」。

![步骤截图](./images/img-07.jpg)

就像这样，再选择「使用下面的 DNS 服务器地址」，填入 `8.8.8.8`（谷歌的 DNS；如果有更好的 DNS 就填更好的）。

**腾讯云 DNS**

- IPv4：`119.29.29.29`

**114 DNS**

- IPv4：`114.114.114.114` / `114.114.115.115`

**Cloudflare DNS**

- IPv4：`1.1.1.1` 和 `1.0.0.1`
- IPv6：`2606:4700:4700::1111` 和 `2606:4700:4700::1001`

#### 3.1.2 下载原神国际服客户端

1. 打开浏览器，使用必应搜索 **Genshin Impact**，或打开官网：

   <https://genshin.hoyoverse.com/en>

   （文中旧链为 `https://genshin.mihoyo.com/en`，现多已跳转至 Hoyoverse。）

   注：如果打开太慢或根本打不开，就开一个加速器。（打开速度慢是正常现象，毕竟服务器架设在国外。）

2. 点击 **Download**。

![步骤截图](./images/img-08.jpg)

进入后页面上会有四个按钮，对应着各个不同的平台，我们只需要选择 Windows 平台就行了。按照提示进行下载操作即可。

3. **更改国服的快捷方式（可选）**

   如果你不想将国服覆盖掉，那就要把桌面上的「原神」重命名成「原神国服」。如果你没有安装国服那就没有必要了，直接跳到下一步。

4. 双击 `.exe` 安装包，并按照提示进行安装。

![步骤截图](./images/img-09.jpg)

这里建议更改路径，如：`D:\genshinimpact`。如果有其他盘符则可以修改前面的字母「D」。（注意这个盘符必须拥有不少于约 70GB 的空间。）

5. 双击桌面上的「原神」快捷方式（注意图标底下写着 **HOYOVERSE** 的那个）。

打开就是这个画面：

![步骤截图](./images/img-10.jpg)

左下角可以修改游戏本体安装目录；右下角点击「获取游戏」即可安装。（还是不少于约 70GB。）

### 3.2 安卓平台部分（包括 MIUI / Flyme / EMUI / ColorOS 等）

注：这部分是安卓平台；要在 iOS 平台请直接跳转至 3.3 部分。以下演示使用的是基于 Android 12 的 MIUI 13 开发版，其他系统操作可能有些不同。

#### 3.2.1 开启开发者模式（非 MIUI 可跳过）

1. 打开设置 → 我的设备 → 全部参数（有的机型是「关于手机」）。
2. 连点 **MIUI 版本号**（注意不是安卓版本号）。这时开发者模式就打开了。
3. 退出到设置主页，点击「更多设置」。
4. 点击「开发者选项」。
5. 翻到底部，将「启用 MIUI 优化」关闭（无视风险提示继续 doge）。

#### 3.2.2 下载 QooApp 游戏商店

1. 打开浏览器。
2. 在搜索框输入（或直接访问）：

   <https://apk.qoo-app.com>

![步骤截图](./images/img-11.jpg)

3. 点击下方按钮等待下载。

![步骤截图](./images/img-12.jpg)

下载好以后按提示安装，安装完成后就会显示在桌面上了。

4. 打开以后将底下的「快捷登录」向左划。

![步骤截图](./images/img-13.jpg)

点击 **Guest** 选项。

![步骤截图](./images/img-14.jpg)

你就成功进入了！

#### 3.2.3 下载游戏客户端（非游戏本体）

1. 搜索 `genshinimpact`（「原神」的英文游戏名）。
2. 点击下载。

![步骤截图](./images/img-15.jpg)

等待下载完成后按提示安装客户端。

注：如果你无法安装客户端，可以参照上文 **3.2.1** 部分。

## Q&A 问答区

### 1. 为啥注册时发的验证码，邮箱中找不到？

你去「垃圾箱」那一栏看看，可能系统识别为了广告。第二种就是网速慢，过一段时间刷新一次就行了。

### 2. iOS 转区后应用商店没有加速器怎么办？

你可以先在国区 App Store 里下载加速器，再转区下载原神。但如果你已经转区好了，就先下原神再转回国区下载加速器，效果是一样的。

### 3. 加速器要实名咋办？

按各加速器平台当前合规要求完成实名即可；不要使用他人身份信息。

### 4. 转国际服的优点、弊端

首先是氪金不太方便，通常需要 VISA 等国际支付方式，也可以找人代充，或者找有索尼主机的小伙伴借来绑定一下再充值。还有就是被盗号后相对更难找回，但如果你有定期换密码的习惯，那也没问题。

其实说实话，国际版最大的优点就是没有离谱的实名 / 防沉迷限制；如果不在周末的晚上玩原神，国际服可能会是你更舒服的选择。

### 5. 国际服有类似米游社的社区吗？

还真有！叫 [HoYoLAB](https://www.hoyolab.com/)（译名：忽悠实验室），唯一的问题就是米哈游做了锁区。
